💡 Dicas de Web Design

Para Links

  • Sempre use textos descritivos nos links
  • Links externos devem abrir em nova aba (target="_blank")
  • Mantenha a consistência nos estilos de links
  • Use :hover para feedback visual

Para Imagens

  • Sempre use o atributo alt para acessibilidade
  • Otimize o tamanho das imagens para web
  • Use formatos apropriados (JPEG, PNG, WebP)
  • Defina width e height para evitar layout shift
